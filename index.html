② 从文本创建词集

支持 .txt / .csv / .md，每行一个词条。可拖拽文件到下方区域，或点击选择。也可直接粘贴步骤 1 提取的文本。
■
点击选择文件，或拖拽到此
支持格式：.txt / .csv / .md / .tsv（直接读取）· .pdf / .docx（自动提取文本）· .json（直接导入词条）
解析方式：PDF 和文本文件默认使用服务器端 Python 解析器（pdfplumber + 编号词条识别，支持双栏排版和 OCR 断词）；粘贴文本使用浏览器端解析。
词条格式（每行一条，制表符或 | 分隔，列顺序任意）：
word  词性 + 释义 → 释义模式
word  释义  英文例句  中文翻译 → 例句挖空模式（推荐）
JSON 格式：[{ "word": "abase", "def": "贬低", "sentence": "...", "translation": "..." }] 或 { "name": "...", "items": [...] }
也可粘贴到下方文本框（会覆盖文件解析）。
